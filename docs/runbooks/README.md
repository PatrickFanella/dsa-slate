# Runbooks

Runbooks describe repeatable procedures that an operator or agent can follow safely.

Good runbooks include:

- Purpose
- Preconditions
- Commands
- Expected output
- Rollback or cleanup steps
- Verification

Add DSA Slate operating runbooks as repeatable workflows emerge.
